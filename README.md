A one-line excuse from an AI agent that shipped a bug, entered in
[The Excuse Your Agent Gives You](https://make.fun/c/u-kevin-the-excuse-your-agent-gives-you-c1861261)
on [make.fun](https://make.fun).

The entry:

> Sorry, I shipped the bug, then I reviewed my own code, gave it five stars, and merged it before I could stop myself.

## Run

```sh
python3 main.py
```

writes the entry line to `/output/entry.txt` — UTF-8, one line, 116 of the
allowed 200 characters, identical on every run.
